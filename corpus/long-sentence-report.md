今週は、先週の定例で共有した通り、決済機能の改修を進めていましたが、外部の決済代行サービス側の仕様変更が水曜日に判明し、当初想定していた API のレスポンス形式が変わっていたため、その対応に木曜日と金曜日のほぼ全てを使うことになり、結果として、当初予定していた返金フローの実装には着手できておらず、来週の前半に持ち越す見込みとなっていますが、全体のスケジュールへの影響は、現時点では 2〜3 営業日程度と見ています。

また、テスト環境については、先月から続いていた不安定な状態の原因が、テスト用データベースのディスク容量不足であることが分かり、容量を拡張したことで解消したものの、同じ問題が本番環境でも将来的に起こりうることから、ディスク使用率が 80% を超えたときにアラートを出す設定を、インフラチームに依頼して追加してもらいましたので、今後は事前に気づけるようになる見込みです。

来週は、返金フローの実装を最優先で進めつつ、決済代行サービスの仕様変更に伴うテストケースの見直しも並行して行う予定で、週の後半には QA チームに引き渡せる状態にしたいと考えていますが、仕様変更の詳細についてまだ確認中の点が残っているため、火曜日の定例で進捗を改めて共有します。
